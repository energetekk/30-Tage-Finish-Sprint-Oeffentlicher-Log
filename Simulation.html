30-Tage Sprint Simulation

Realistische Szenarien für 3 Skill-Levels (Modul: Bronze -> 13 Tage Sprint)
📊 InvoiceFlow - Micro SaaS für Freelancer

🌱 Anfänger-Pfad

Learning-Focused

Startbedingungen

  • Vorwissen: Keine Programmier-Erfahrung
  • Tools: Nutzt No-Code/Low-Code (Airtable, Zapier, Carrd)
  • Zeitplan: ~1h/Tag (50% Learning, 50% Building)
  • Ziel: Funktionaler Prototyp mit Kerndaten
Tag 1 ~60 Min
Research & Validierung
Verstehen des Problems: Freelancer tracken Rechnungen manuell in Excel oder gar nicht. Recherche wie andere das lösen. 5 Freelancer interviewt (per LinkedIn DM).

Deliverables:

  • Problem validiert (Freelancer brauchen das wirklich!)
  • 5 Interview-Notizen in Google Docs
  • Liste der Kern-Features (Invoice list, Status tracking, Reminders)
Tag 2-3 ~60 Min/Tag
Airtable Setup & Datenmodell
Lernt Airtable Basics (20 Min YouTube Tutorial). Erstellt Datenbank mit Tabellen: Invoices (Nummer, Kunde, Betrag, Status, Fälligkeitsdatum). Fügt erste Test-Daten ein.

Deliverables:

  • Airtable Base mit "Invoices" Tabelle
  • 5 Spalten: Invoice #, Client, Amount, Status, Due Date
  • 10 Test-Einträge angelegt
Tag 4-5 ~60 Min/Tag
Landing Page mit Carrd
Erstellt simple Landing Page: "InvoiceFlow - Nie wieder Rechnungen vergessen". Erklärt das Problem, zeigt Screenshot von Airtable, Waitlist-Formular mit Typeform.

Deliverables:

  • Landing Page live auf invoiceflow.carrd.co
  • Typeform für Waitlist integriert
  • Screenshot der Airtable-Lösung als "Demo"
Tag 6-7 ~60 Min/Tag
Zapier Automation Setup
Lernt Zapier Basics. Erstellt Zap: Neue Invoice in Airtable → Email-Reminder 2 Tage vor Fälligkeit. Testet mit eigenen Test-Invoices. Funktioniert!

Deliverables:

  • Zapier Zap: Airtable → Gmail
  • Email-Template für Reminders erstellt
  • 3 Test-Emails erfolgreich verschickt
Tag 8-10 ~60 Min/Tag
User Testing & Feedback
Schickt Airtable-Link an 3 Freelancer-Freunde zum Testen. Sammelt Feedback: "Funktioniert, aber ich will mein eigenes Dashboard". Plant Version 2.0 mit richtigem Interface.

Deliverables:

  • 3 Beta-User nutzen die Airtable
  • Feedback dokumentiert (Google Docs)
  • Waitlist: 12 Sign-ups auf Landing Page
Tag 11-13 ~60 Min/Tag
Polish & Mini-Launch
Verbessert Landing Page (Testimonial von Beta-User), postet auf Reddit r/freelance und in 2 Freelancer Facebook-Gruppen. Erste zahlende User? Noch nicht - aber 45 Waitlist Sign-ups!

Deliverables:

  • Landing Page mit User-Testimonial
  • Reddit Post: 23 Upvotes, 8 Comments
  • Waitlist: 45 Sign-ups total
  • 3 Beta-User aktiv (alle kostenlos)
Ergebnis nach 13 Tagen: Funktionaler Prototyp mit Airtable + Zapier. 45 Waitlist Sign-ups, 3 aktive Beta-User. Noch kein Bezahl-Produkt, aber Problem validiert! Nächster Schritt: Lernen zu coden oder einen Developer finden.

🚀 Fortgeschritten-Pfad

Build-Focused

Startbedingungen

  • Vorwissen: Kann HTML/CSS/JavaScript, kennt React Basics
  • Tools: Next.js + Supabase + Vercel
  • Zeitplan: ~1h/Tag (80% Building, 20% Learning)
  • Ziel: Web-App mit Auth, CRUD, deployed
Tag 1 ~60 Min
Quick Validation & Tech Stack
Posted auf Twitter: "Building InvoiceFlow - simple invoice tracking for freelancers. Who'd pay $5/mo for this?" → 23 Likes, 7 "I would!" replies. Stack gewählt: Next.js + Supabase.

Deliverables:

  • Twitter Thread mit 23 Likes
  • Tech Stack dokumentiert (Notion)
  • Supabase Projekt erstellt
Tag 2-3 ~60 Min/Tag
Next.js Setup + Database Schema
`npx create-next-app invoiceflow`. Supabase Schema: Users, Invoices (id, user_id, client_name, amount, status, due_date). RLS Policies für User-Isolation.

Deliverables:

  • Next.js App läuft lokal
  • Supabase DB mit 2 Tables
  • RLS Policies getestet
Tag 4-6 ~60 Min/Tag
Auth + Dashboard UI
Supabase Auth (Email/Password). Dashboard Page: Liste aller Invoices, Status-Filter (Paid/Pending/Overdue), simpel mit Tailwind CSS gestylt.

Deliverables:

  • Login/Signup funktioniert
  • Dashboard zeigt User's Invoices
  • Status-Filter funktional
Tag 7-9 ~60 Min/Tag
CRUD Features
Create Invoice Form (Client Name, Amount, Due Date). Edit/Delete Funktionen. Status Update (Mark as Paid). Alles funktioniert mit Supabase API.

Deliverables:

  • Add Invoice Form (funktional)
  • Edit/Delete Buttons
  • Status Update funktioniert
Tag 10-11 ~60 Min/Tag
Landing Page + Deploy
Landing Page mit Next.js (Hero, Features, Demo Screenshot, Waitlist). Deploy auf Vercel (free tier). Custom Domain: invoiceflow.app ($12/year).

Deliverables:

  • Landing Page live
  • App deployed auf Vercel
  • invoiceflow.app Domain connected
Tag 12-13 ~60 Min/Tag
Beta Testing & First Users
Schickt Link an Twitter-Follower die Interesse gezeigt haben. 8 User testen. 2 Bugs gefunden und gefixt. Sammelt Testimonials. Plant Stripe Integration für nächste Woche.

Deliverables:

  • 8 Beta-User aktiv
  • 2 kritische Bugs gefixt
  • 3 User-Testimonials gesammelt
  • Roadmap: Stripe (nächste Woche), Email Reminders (Woche 3)
Ergebnis nach 13 Tagen: Funktionale Web-App live auf invoiceflow.app! 8 aktive Beta-User, Auth funktioniert, CRUD komplett. Noch kostenlos, aber bereit für Stripe Integration. Nächster Schritt: Monetarisierung + Email Reminders.

⚡ Profi-Pfad

Scale-Focused

Startbedingungen

  • Vorwissen: Production-ready Developer, kennt Best Practices
  • Tools: Next.js + Supabase + Stripe + Resend + Vercel
  • Zeitplan: ~1h/Tag (95% Building, 5% Learning)
  • Ziel: Revenue-generating SaaS, skalierbar
Tag 1 ~60 Min
Strategic Setup & Boilerplate
Nutzt production-ready boilerplate (z.B. ShipFast). Konfiguriert: Next.js 14 App Router, Supabase Auth + DB, Stripe Checkout/Webhooks, Email (Resend), Analytics (Plausible). Alles in 60 Min weil Templates.

Deliverables:

  • Next.js Boilerplate deployed (Vercel)
  • Stripe Test Mode konfiguriert
  • Supabase + Resend connected
Tag 2-3 ~60 Min/Tag
DB Schema + Auth + Onboarding
DB Schema: Users (mit subscription_status), Invoices (mit relationships), Stripe Events. Auth Flow komplett (Email/Google). Onboarding: 3-Step Form (Name, Company, First Invoice).

Deliverables:

  • DB Schema production-ready (mit Indizes)
  • Multi-provider Auth (Email + Google)
  • Onboarding Flow funktional
Tag 4-6 ~60 Min/Tag
Core Features + Payment
Dashboard mit Invoices (Table mit Sort/Filter), CRUD, Status Management. Stripe Integration: $9/mo Subscription, Cancel Flow, Billing Portal. Webhook Handler für Events.

Deliverables:

  • Full CRUD mit optimistischem UI
  • Stripe Checkout funktioniert
  • Webhooks handhaben subscription.created/deleted
  • Billing Portal Link
Tag 7-8 ~60 Min/Tag
Email Automation + Reminders
Cron Job (Vercel Cron): Täglich checken welche Invoices in 2 Tagen fällig sind → Email via Resend. Email Templates professionell designed. User kann Reminder-Settings anpassen.

Deliverables:

  • Vercel Cron Job läuft täglich
  • Reminder-Emails verschickt (professionelles Template)
  • User kann Reminder-Einstellungen ändern
Tag 9-10 ~60 Min/Tag
Landing Page + SEO + Analytics
Production-grade Landing Page (Hero, Social Proof, Features, Pricing, FAQ). SEO optimiert (Meta Tags, Schema.org). Analytics (Plausible), Conversion Tracking. Domain: invoiceflow.com.

Deliverables:

  • Landing Page conversion-optimiert
  • SEO: Meta Tags, Sitemap, robots.txt
  • Analytics + Conversion Funnel
  • invoiceflow.com live
Tag 11-13 ~60 Min/Tag
Launch + Marketing + First Revenue
Launched auf Product Hunt (#3 Product of the Day!), Indie Hackers, Twitter, Reddit. Erste zahlende Kunden am Launch-Tag! SEO bringt erste organische Signups.

Deliverables:

  • Product Hunt Launch: #3 of the Day
  • 134 Sign-ups in 3 Tagen
  • 8 zahlende Kunden ($72 MRR)
  • Traffic: 450 Visitors, 15% Conversion
  • 2 User Testimonials live auf Landing Page
Ergebnis nach 13 Tagen: Production-ready SaaS mit $72 MRR! 134 total Sign-ups, 8 zahlende Kunden, Email Automation läuft, SEO optimiert. Nächster Schritt: Growth (SEO Content, Affiliate Program, Feature Expansion).
